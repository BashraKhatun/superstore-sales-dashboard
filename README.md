Superstore Sales Dashboard 📊

📌 Project Overview

This project is "Task 1 of my Data Analyst Internship". The objective was to analyze a Superstore sales dataset and transform the raw data into a meaningful and interactive sales dashboard using Google Sheets.

The dashboard provides an overview of sales performance, profitability, order volume, category performance, regional performance, and monthly sales trends.

🎯 Key Analysis

The dashboard includes:

->Total Sales
->Total Profit
->Total Orders
->Profit Margin
->Sales by Category
->Profit by Category
->Sales by Region
->Monthly Sales Trend from 2023–2026

📊 Dashboard Highlights

#Key Performance Indicators (KPIs)

The dashboard calculates and displays:

* Total Sales: 2,326,534.354
* Total Profit: 292,296.8146
* Total Orders: 10,194
* Profit Margin: 12.56%

#Category Analysis

Sales and profit were analyzed across:

* Office Supplies
* Furniture
* Technology

#Regional Analysis

Sales performance was compared across four regions:

* Central
* East
* South
* West

#Monthly Sales Analysis

A monthly sales trend was created to understand how sales changed over the period 2023–2026.
